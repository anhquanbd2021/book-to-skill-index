Guide

The file layout is the index.

A book-to-skill conversion doesn't put the book in the skill. It puts a way to find the book in the skill: a small always-loaded manifest plus one distilled leaf per chapter. This page is what the lab is actually showing.

The shape

A generated skill for The Queue at the Edge is six files:

skill/
├── SKILL.md          manifest — always loaded (~453 tok)
└── chapters/
    ├── ch01.md       distilled leaf — on demand
    ├── …
    └── ch06.md       distilled leaf — on demand
  • skill/SKILL.md — the manifest: core mental model, the chapter map (each leaf's title, coverage phrases, source ref), and the escalation rule. ~453 estimated tokens. Always loaded.
  • skill/chapters/*.md — one distilled leaf per chapter, ~100–150 estimated tokens each. Loaded only when the manifest routes a question to it.

Mode A pays for all six full chapters (~2,257 estimated tokens) every question. Mode B pays for the manifest plus one leaf (~570–600). Same question, ~4x cheaper at toy scale — on a real book the source repo measures ~24x, because a real book is ~50x this fixture.

The lossy edge

Question 3 asks for the Lisbon ring's node count. The distiller kept the lesson (quorum must track live membership) and dropped the number as trivia. The index routes correctly — ch02 — and then the context contains no node count. Nothing in the leaf says "this was dropped," so the miss is confident.

The leaf's Source ref field is the fix: a miss escalates by loading the real chapter once (~370 more tokens), finds "fourteen nodes," and still costs less than half of dumping the book. An index you can escalate through beats an index you have to trust.

Honest limits

  • "Answering" is evidence lookup: a mode is correct iff its loaded context contains the question's marker string. No model is called — the lab shows context cost and coverage, which are the parts the post's 24x claim is actually about.
  • Token counts are estimates (~4 chars/token), consistent enough to compare modes, not to bill anyone.
  • Routing here is substring scoring over covers phrases; a real skill is routed by the model reading the manifest. The lab's routing exists to make the selection step inspectable.
  • The corpus is a fixture — six short chapters. A real book inflates both numbers but widens the ratio, because the manifest stays ~5K while the book grows unboundedly.
  • The distilled leaves were written by hand to be good distillations. A real converter's output quality is the variable this demo can't show.

File map

  • public/book.mjs — the corpus: full chapters + distilled leaves + MANIFEST
  • public/index.mjs — token accounting + manifest routing
  • public/modes.mjs — whole-book, skill-index, and escalate modes
  • public/questions.mjs — the three scripted questions + markers
  • examples/ — the same corpus as inspectable files (tests assert the mirror)
  • scripts/index-report.mjs — CLI side-by-side with claim checks
